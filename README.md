# Fairytale Project: Original Website

The earlier website source for the Fairytale Project, kept as a record of how the archive was originally presented.

This repository contains the older PHP site and its supporting files. It provides historical context for the [newer static rebuild](https://github.com/david-steinbroner/fairytale-project-static).

If you want to explore the current archive, visit [fairytaleproject.net](https://www.fairytaleproject.net). If you want to work on the rebuilt site, start with the newer repository.

This is historical source, not a ready-to-run installation package. Recreating the old site would require its original server and content setup.
